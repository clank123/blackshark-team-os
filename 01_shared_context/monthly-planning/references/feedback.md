# 结果怎样修正人群库

结果可能改变目的、投入或后续安排时，同时用[共用质量标准](workflow-quality.md#结果回来怎样改判)处理原项目；不只更新人群卡。只读受影响部分。

先读取当前库、后续修订、当时判断与动作版本，不能只用当前方案解释过去结果。每次只处理新反馈影响的主张。

## 先弄清结果能说明到哪

依次核：来源可靠和独立吗 → 动作实际发生吗 → 顾客有机会看见/使用吗 → 产品现场兑现吗 → 观察期到期吗 → 同期有哪些变化 → 结果对应哪条解释。

- 未发布、未上线：修执行，需求未被检验。
- 已做但曝光、供给或窗口不够：记录限制，不能把没有订单等同没有需求。
- 订单增长但同期降价、演出和投放变化：记录增长与相关性，不能独归因于某卡片或文案；同星期比较也不自动证明因果。
- 有明确选择理由与实际消费：支持相应机制和适用条件，规模、总体增量仍需合适分母与比较。
- 计划与表未更新：先保留未知，核真实反馈，不判团队没做。

执行、顾客行为、经营贡献、品牌/跨店影响、方法减负分别结算。利润、复来、首次来店等没有口径不造数。角色模拟输出不能回流为证据。原问题回答了就更新原状态；没回答继续保留，不换个名称逃掉旧问题。

## 修订具体主张

允许：增加新依据、缩小范围、降为待查、拆分、合并、撤回、标旧阶段。次数增加不是自动升级标准；未覆盖的人群不是不存在。事实纠错可在已有维护授权内直接改；影响已定投入时只重开受影响的经营决定。

选择理由、提供条件或经济方式被新材料挑战时，按[营销选择](marketing-choice.md)检查目的、主次与下一笔投入是否要变，并修改对应关键产出和验收。模拟材料保留独立假设分支，不合并为真实门店状态。

每次留下：稳定卡片/主张ID、旧说法、新来源及覆盖、支持/反例/替代解释、新说法与状态、影响哪个方向/动作、仍未知、日期、基准版本与新版本、修改者。旧文本不删除。已有行动收益不证明整张卡，单次失败也不抹掉全部需求。

卡片与变更日志一起才是“当前库”。读取时必须合并最新有效修订；引用旧卡要同时带其修订。若把变更整理成新版库，先校验全部保留且指针可回读，再切换当前入口，旧版继续可追溯。跨店迁移只生成候选，不带来原店客群比例、预算或验证结论。

## 轻量观察

先用已有交易、评价、咨询与自然接待记录。确需补动机时围绕当前选择收集少量具体来因/放弃理由，同时保留其他/不知道、时间与选择方式；便利样本不推整店比例。观察前说清比较口径、窗口与哪些情况会改判，不事后从很多指标中只挑上涨的。没有足够比较时先把变化记为观察，不包装成实验成功。

## 让模型少犯错，而不是越来越自信

同时查支持与反证、谁没被现有平台覆盖、免费/合作与自然来源、当前阶段是否变了、顾客想法与实际动作是否一致。记录“建议已采用”“实际执行”“结果支持”“可以跨店复用”各自证据。自然工作中观察新增有效遗漏、实质返工、人的资料搬运负担与经营结果；没有证明比直接审阅更好，就保留证据卡，省掉人物表演。

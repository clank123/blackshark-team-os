# 从资料到方向和动作

完整月规划先按[共用质量标准](workflow-quality.md)接通目的、推进范围、关键产出与验收；下文补充资料和人群卡的具体方法。

## 接回与补取

先从用户指定项目或该店资料索引读取：当前阶段与门店身份、有效决定/授权、上月目标和实际执行、结果窗口、未解问题、当前人群库及修订、方案与推进表。查数据发生日期和有效范围，不按文件较新就认定内容较真。旧结果未到期仍带到新月。

第一次或重大变化时盘点相关后台的报表与字段，记录“回答哪个问题、已取范围、没取原因”。每月只补新增、修订、反例和影响本轮选择的缺口。报表完整性、分页/行数、覆盖日期、退单/撤销、跨午夜营业日、套餐母子项与重复来源都要核；数据与口径对不上先限制相关推断。平台隐藏值不是零。

交易回答消费结构、时间、价格与兑现，评价/咨询回答明确表达的理由和摩擦，菜单/现场/成本回答能否兑现与是否值得，计划/反馈回答实际做过什么。平台新客不是全店首客，订单不是人数，券购买不是核销。同一用户跨平台不因文案相似就确认身份；同源叙事不重复加权。合作、免费体验、主动征集和未知来源单独标注。只存必要匿名证据，联系人和支付信息不进入卡片。

停止补取的条件：已有资料足够作当前有边界的选择；剩余缺口不改变该阶段动作；或取数成本超过选择价值。关键缺口写清“缺什么、会改变哪项选择、谁有条件补”，不把所有后台字段设为每月必填。

## 建立或复核人群卡

每条解释区分原表达/行为、支持的事实、假设、未知与反例。至少比较一个有实际可能的替代解释，不为证明直觉挑评论。

按[营销选择](marketing-choice.md)分清需要、决策角色与关系阶段；只拆会改变经营选择的差异。卡片可以交叠，不将活动、渠道、老客和消费场景当成同层互斥客群。

卡片按以下字段保存，字段可映射既有库，不要求另起一张表：

| 内容 | 要求 |
| --- | --- |
| 稳定编号、适用门店/阶段、状态 | 旧卡保持编号；跨店使用是候选迁移，不能迁移份额与效果 |
| 像人的描述 | 何时、与谁、想完成什么、阻力来自什么；未被观察的年龄职业人格不填 |
| 选择过程 | 为什么考虑、还会选什么、顾虑什么、什么会放弃；顾客明确说的与AI推测分开 |
| 支持与反例 | 可回读来源ID/日期/原文位置、样本范围、商业来源和重复关系 |
| 能改变什么 | 具体产品、说明、时段、现场或承接动作；没有差异就考虑合并 |
| 可识别信号与规模 | 信号可用于未来观察但不是已有身份标签；份额无合适分母则未知，可重叠不能硬凑100% |
| 修正条件 | 哪类新材料会支持、限制、拆分、撤回这条解释；保留不知道的事 |

合成人物话语必须标明是概括，不能冒充访谈。卡片没有某类任务，仅说明当前资料未覆盖，不说明不存在。

## 选择月度方向

同时比较：真实需求支持、目前经营问题、触达能力、产品/现场兑现、贡献与成本、人员时间、不同场景冲突。至少考虑沿用原方案/不追加投入。给具体推荐与代价，不伪造综合评分替代判断，不先强迫用户交主目标。

目标写清希望哪种顾客行为变化、对经营的意义、场合和期间、资源边界、怎样测量。没有可信基线/成本，不能随意写增长比例、ROI或利润；可先定准备或观察目标，并明确它还不是经营增长目标。

先保留常规分析已有结论，再让相关卡片检查方案：哪一处回应了需要、还缺什么、怎样可能不选、依据是什么、怎样验证。只记录卡片带来的有效新增认识；没有增量就省略角色扮演。

动作串起来：**已观察的障碍 → 拟改做法 → 希望行为 → 经营意义 → 当前关键产出 → 观察/继续/停止条件**。沿原任务编号，不重复造活动，不让新主线吞掉仍需并行的工作。最后检查门店能否接住、需要谁核实、哪些真实决定尚未授权，再交原动作编译与推进渠道。

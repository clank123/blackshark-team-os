# 胡子品牌共享真值

适用范围：门店月度经营、活动、内容、产品表达、平台首屏和现场话术。

# 品牌为什么存在

- 胡子不是用酒制造距离感，而是用酒降低进入门槛。
- “望喜”的底层愿望，是让人看到、喝到、进入这个品牌时感到开心。
- 好喝不是众多卖点之一，而是所有表达成立的前提。
- 好玩不是表面搞怪，而是用具体产品、场景和表达让用户发现“酒原来还可以这样”。
- 平易近人不是低质，而是不要求用户先理解文化、术语、工艺或身份，才有资格进入。
- 品牌表达优先服从真实产品体验和真实用户反应，不为了框架完整牺牲单品生命力。

# 已成立的表达

- 酒可以简单、好喝、开心，第一口就能理解。
- 产品和门店应该让用户更容易尝试、更愿意带朋友来，而不是先证明品牌多会讲文化。
- “葵”证明胡子的价值可以从用户喝完的一声惊喜开始，再逐步长出完整故事。
- 说“开心”，必须对应更容易进入、尝试和复来的具体场景。
- 说“好玩”，必须对应产品、包装、活动或话术中的具体反差。
- 说“年轻”，必须对应直接、跳脱、不规整但仍然清楚的表达方式。

# 不该怎么讲

- 不把太重的酒文化当成用户进入品牌的门槛。
- 不用复杂工艺和风味教育压住产品本身的好喝与惊喜。
- 不在证据不足时过早拔高福州文化、茉莉花文化、中国元素或宏大品牌升级。
- 不使用让产品显得很贵、很难懂、很需要解释的语言。
- 不为了视觉花哨、活动热闹或系列完整，牺牲门店真实体验和用户复来理由。

# 用在月度经营时

每个方案至少检查：

1. 本月动作是否让目标用户更容易理解为什么来这家店？
2. 品牌表达是否有对应产品、场景或用户证据？
3. 是否保护了该门店自己的长期角色，而不是复制其他门店？
4. 去掉文化解释后，产品体验和用户理由是否仍然成立？

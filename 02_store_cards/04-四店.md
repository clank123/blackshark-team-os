# 基础身份

- 门店：四店／胡子精酿福一路店
- 位置：福州鼓楼区福一路
- 类型：社区小店、酒水体验与精酿尖货店

# 品牌关系与门店角色

- 主角色：胡子体系中的高品质酒水体验门店。
- 次角色：社区白领下班后的轻放松选择。
- 成功信号：品质客把它当作“想认真喝点好酒”的稳定去处。

# 核心客群

- 约 30 岁、对精酿品质敏感且愿意为品质买单的白领。
- 想下班放松、但不想太吵的社区用户。
- 不以强家庭、强夜店和纯打卡用户为核心。

# 核心场景和体验

- 关键词：尖货、放松、品质、小空间。
- 体验：在不吵不累的空间里喝到值得专程来的好酒。

# 主时段与弱时段

- 历史主时段：周五、周六 21:00—24:00。
- 工作日更偏下班轻放松，周末更偏品质消费。
- 非晚间和非周末为历史弱时段，当前表现待门店确认。

# 产品结构和优势资产

- 以酒水为核心，不依赖汉堡、烧烤或大场景。
- 优势资产：尖货首发、精选客啤、胡子自有高品质酒款与一定定价能力。

# 适合动作

- 尖货首发、轻主题尝鲜、酒款教育但讲人话。
- 白领下班放松、品质内容和社区稳定复来。

# 禁止动作

- 过度热闹化、夜店化和定位模糊的泛活动。
- 每个节日都硬做大动作。
- 用低价冲量损害酒水品质心智。

# 长期基因

四店依靠纯粹酒水体验成立。小、安静和专业但不端着，是它与大场景门店的差异；增长动作必须继续保护“喝好酒”的理由。

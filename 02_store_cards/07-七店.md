# 基础身份

- 门店：七店／胡子精酿湖东路店
- 位置：福州鼓楼区五四路与湖东路交界
- 类型：市中心前店后厂、城市升级旗舰店

# 品牌关系与门店角色

- 主角色：胡子在市中心的旗舰表达。
- 次角色：承接白领消费力和高品质多场景消费。
- 成功信号：用户认为这里是更完整、更精致、更进阶的胡子，而不是更大的五店。

# 核心客群

- 市中心办公楼白领、有品质需求且愿意消费的年轻客群。
- 下班放松、聚会、餐酒综合体验和潮流尝新用户。
- 不以只看低价、不在意体验的用户为核心。

# 核心场景和体验

- 关键词：市中心、升级版、综合旗舰、白领下班。
- 体验：在市中心一次获得丰富酒款、品质餐食和更完整的胡子体验。

# 主时段与弱时段

- 历史暂定主时段：21:00—24:00。
- 机会时段：白领下班后与周末综合消费。
- 弱时段和工作日／周末差异仍需本月确认。

# 产品结构和优势资产

- 丰富酒款、跳进厨房、胡烤组成综合组合。
- 优势资产：市中心位置、前店后厂、约 42+ 酒款的历史丰富度、汉堡和烧烤联动。

# 适合动作

- 白领下班场景、旗舰节点、品质内容和组合消费。
- 酒款尝新、餐酒搭配、市中心办公楼周边触达。

# 禁止动作

- 降级成普通热闹店或只靠低价冲量。
- 只复制五店，不建立市中心旗舰的独立价值。
- 产品很多但不给用户一个清楚的首选理由。

# 长期基因

七店必须证明胡子在市中心的升级价值：更完整不等于更复杂，更高投入必须换来更明确的白领场景、品质感和独立选择理由。

# 基础身份

- 门店：二店／胡子精酿金山店
- 位置：福州金山片区
- 类型：社区餐酒叠加、R&B 音乐场景店

# 品牌关系与门店角色

- 主角色：保住金山社区餐食、汉堡、外卖与熟客底盘。
- 次角色：叠加小董音乐 IP 与 R&B 夜间场景，形成金山微醺入口。
- 成功信号：用户同时知道“想吃汉堡可以来”和“想听 R&B、喝第一杯也可以来”。

# 核心客群

- 金山社区餐酒用户、旧二店熟客、家庭与外卖用户。
- 下班晚餐、第一杯、朋友局和喜欢 R&B 的年轻客群。
- 不以重夜店、纯商务应酬或只追大型演出的用户为核心。

# 核心场景和体验

- 关键词：餐酒叠加、R&B、金山微醺。
- 体验：餐段稳定吃到汉堡和社区餐食，夜间在家附近听有质感的 R&B，轻松喝第一杯和第二杯。

# 主时段与弱时段

- 午市：12:00—14:00，汉堡、外卖与家庭客底盘。
- 晚餐：18:00—20:30，餐食为主，音乐作为背景。
- 过渡：20:30—21:00，灯光与音乐渐变。
- 历史夜间主时段：周五、周六 21:00—24:00，需结合当前数据验证。

# 产品结构和优势资产

- 餐段以孤独汉堡、外卖和社区熟客信任为底盘。
- 夜间叠加低理解成本第一杯、稳定酒款和 R&B 氛围。
- 优势资产：旧店熟客、汉堡口碑、小董音乐 IP、官方账号和金山社区位置。

# 适合动作

- 餐酒全时段表达、R&B 质感内容、下班微醺与周末朋友局。
- 小董个人内容与门店官方账号分工。
- 点评／美团首屏与套餐承接、私域预约和复访。

# 禁止动作

- 砍掉餐食、外卖、家庭客和旧熟客资产，只做夜场。
- 只复制旧一店 R&B 记忆。
- 把小董个人号和门店账号混成一件事。
- 只靠节点热闹，不设计到店、加购和复访。

# 长期基因

二店是金山社区利润底盘与夜间音乐场景的叠加，不是从餐馆硬切成酒馆。餐食信任负责稳定，R&B 负责形成更清楚的夜间复来理由。

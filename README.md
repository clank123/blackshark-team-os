# 黑鲨团队 AI 工作台 v0.1

这是黑鲨门店运营团队 AI 工作台的公开分发版。它帮助使用者基于统一门店上下文，把每月 20 日前确认的经营会议内容整理成：

1. 一份七段式月度运营方案。
2. 一张只含一个业务表的运营推进表。

## 公开仓库

- 仓库入口：<https://github.com/clank123/blackshark-team-os>
- 仓库为公开可见，下载和读取不需要 GitHub 账号。
- 公开仅用于降低团队接入门槛，不代表门店卡中的待验证内容是实时对外口径。
- 不要向公开仓库写入当月经营数据、员工材料、顾客信息或飞书内部链接。

## 适用范围

供黑鲨门店运营协作使用。公开仓库不授予任何人黑鲨知识库的编辑权限；飞书发布仍以操作者本人的权限为准。

## 每次需要提供

- 目标门店与月份。
- 月度经营会议材料。
- 已确认主方向与次方向；没有次方向时明确写“无”。
- 最后拍板人、运营推进人、门店落地人。

## 最短使用流程

1. 第一次使用时，让 Codex 下载公开仓库并打开仓库根目录。
2. 每次开始任务前先同步公开仓库更新。
3. 把本月材料放进 `03_projects/YYYY-MM-门店名称/00-input/`。
4. 向 Codex 说明：“为 X 店生成 YYYY 年 MM 月运营方案，我已提供月度会议内容。”
5. 先检查预览和缺口。
6. 只有确认本次预览后，才发布飞书文档和配套推进表。
7. 发布完成后检查回读验收结果。

## 边界

- 门店卡的“长期基因”可以复用，“当前状态”必须看数据截止日期。
- 未确认事项只能进入“待拍板”，不能写成已决定。
- 团队实践先进入 `05_reviews/月度复盘候选/`，不能直接覆盖共享真值。
- 共享上下文、门店卡、模板和 Skill 由发布者维护，团队成员的月度材料只写入本机 `03_projects/`。

## 入口

- 第一次使用：阅读 `团队接入卡.md`。
- 项目规则：由根目录 `AGENTS.md` 提供。
- 门店入口：`02_store_cards/00-七店索引.md`。
- 月度入口：`04_templates/月度会议输入模板.md`。

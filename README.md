# 黑鲨团队 AI 工作台 v0.2

这是可在个人知识库中使用的黑鲨门店运营完整知识包，不是单独一个 Skill。Skill 负责路由和编译；完整知识包同时提供共享上下文、七店门店卡、模板和工作台骨架，让每月运营任务有一致的事实来源、交付结构与个人工作区。

## 获取与使用模式

- 公共仓库：<https://github.com/clank123/blackshark-team-os>。没有 GitHub 账号也可以下载和读取。
- 不上传实时经营数据、员工信息、顾客信息或内部飞书链接到公共仓库。
- **嵌入已有 Obsidian**：将完整知识包匹配到已有知识库；做黑鲨任务时打开 `黑鲨门店运营` 或仓库根层。
- **独立工作区**：没有知识库时，直接以完整知识包作为独立工作区；做黑鲨任务时同样打开 `黑鲨门店运营` 或仓库根层。

## 三类内容归属

- **官方基线**：共享上下文、门店卡、模板和正式规则。官方基线可以修改，也可以本地编辑；编辑前提示后续同步风险。公共版本更新时如有本地差异，暂停自动更新，展示本地差异并说明同步影响，待操作者确认处理方式。
- **个人扩展**：仅对本人有效的配置、输入、产物、复盘和个人结构。可以自由修改，默认只在本地保留；个人扩展日常编辑不需要额外确认，只有同步、迁移或同名覆盖时才使用防覆盖门槛。
- **回流候选**：可能被团队复用的经验或证据。提交后由负责人决定是否吸收进官方基线。

更新、迁移或同名覆盖不得静默覆盖；先展示差异和影响，再由操作者确认处理方式。个人目录调整后，在 `00_workspace/工作台地图.local.md` 更新实际位置即可。

## 首次使用

在 Codex 中发送以下统一 prompt：

> 请启用黑鲨门店运营工作台，并帮我匹配当前知识库。先检查和展示建议位置，得到我的确认后再创建或移动文件。

Router 会先识别完整知识包与使用模式，展示建议位置并等待确认；确认后才生成本地地图和个人目录。

## 日常流程

1. Router：读取 manifest，定位或确认 `工作台地图.local.md`。
2. 地图：从地图找到本人的工作目录。
3. 目标门店最小上下文：只读任务相关共享知识和一张目标门店卡。
4. 月度 Skill：根据会议输入生成或预览月度工作。
5. 本地五件产物：
   - `本月运营方案.md`
   - `运营推进表.csv`
   - `运营推进表结构.json`
   - `发布说明.md`
   - `验收结果.md`
6. 可选飞书：本地产物是默认交付，**不默认发布飞书**。只有操作者明确要求时，才使用操作者本人权限和指定位置发布；飞书默认目标为空。

## 每次需要提供

- 目标门店与月份。
- 月度经营会议材料。
- 已确认主方向与次方向；没有次方向时明确写“无”。
- 最后拍板人、运营推进人、门店落地人。

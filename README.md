# 黑鲨团队 AI 工作台 v0.3 试用版

这是沿 blackshark-team-os v0.2 迭代的 v0.3 试用版。负责人和运营使用同一个入口，结合既有方法和本店资料解决月度规划与日常问题。

新使用者下载[版本发布页](https://github.com/clank123/blackshark-team-os/releases/tag/v0.3)的完整 ZIP，先解压，再在 Codex 中把包含 `AGENTS.md` 和 `workspace-manifest.json` 的文件夹打开为本地项目。已经有工作台的成员按[团队接入卡](团队接入卡.md)更新，保留个人材料。单独把一篇说明或 ZIP 附在聊天里，不代表工作台已经启用。

在 Codex 打开这个完整文件夹后，直接说：

> 这是本店下个月的整体方向，请带我梳理到月度方案和推进表。先用现有资料，有影响执行的缺口再问我。

或者：

> 我在这家店遇到这个问题，帮我判断怎么做。需要什么信息请直接问，能先做的先做。

无需先学习目录，也不必填完一份表才开始。`$blackshark-ops-router` 是统一入口；`$blackshark-monthly-ops-compiler` 保留为月度直达入口。

## 每月成果保持一致

- 一份七段式月度运营方案，保存方向、做法、分工、排期和取舍。
- 一张推进表，主项目下展开子任务，保存负责人、期限、状态、验收和实际情况；飞书版本在方案第七段内嵌表视图。

模板有独立版本。AI 使用的 JSON、CSV 和发布验收记录留在项目内部，不要求运营阅读或维护第二套报告。本地预览、真实数据、父子显示和文档内嵌分别报告，未操作飞书就不会声称已发布。

## 方法与门店信息

公共包保存方法、模板和历史门店卡；运营提供的当前会议、观察和经营数据存放在被 Git 忽略的个人工作区。AI 读取当前任务已有资料，按需要更新本地门店当前记录，下次沿用。不会自动同步另一位同事的本地资料，也不会自动回传总部。

已建好的个人地图继续使用。没有地图时可直接对话；需要生成文件时使用本包个人目录。只有迁移、外部位置或覆盖冲突才需要选位置。

# 工作台地图契约

本契约对应 `00_workspace/工作台地图模板.md`。地图模板的全部字段如下：

- 启用状态
- 使用模式
- 知识库根目录
- 工作台根目录
- 个人输入目录
- 个人项目目录
- 正式产物目录
- 个人复盘目录
- 个人补充目录
- 团队回流候选目录
- 飞书默认发布位置
- 最后确认时间

除成员明确选择外部目录外，所有相对路径默认相对工作台根。成员明确选择外部目录时，才在地图中记录该外部路径；不能猜测写入位置。

`工作台地图.local.md` 含个人路径并被 Git 忽略。字段缺失或路径失效时，重新匹配并请成员确认；不因一个字段失效而猜测替换路径。成员可调整个人结构，更新地图即可，不需要重建整个知识库。官方路径变更时，提示个人地图同步风险并重新核验相关路径。

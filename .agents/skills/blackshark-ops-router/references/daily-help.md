# 日常求助

先用现有材料判断卡在哪里；这张表供 AI 选择思路，不给运营填表。

| 卡点 | 思考方向 | 当前应给的结果 |
|---|---|---|
| 不知道该做什么 | 本店角色、客人来店任务、现在最影响结果的环节、可用资源 | 一个建议方向与理由；有实质分歧才比较备选 |
| 有方向但拆不动 | 产品与套餐、讲清楚、讲出去、到店兑现、关系维护的依赖 | 可执行动作与先后，缺口只挂相关动作 |
| 有流量没成交 | 先核对统计口径，再看人群、承诺、入口、价格、购买和现场是否一致 | 优先核查或修改哪一处，怎样判断；不直接判无需求或自动加预算 |
| 没内容想法 | 这次希望谁理解什么或做什么，本店有什么真实产品、场景与素材 | 可用选题、脚本或 Brief；已要求创作就交具体稿 |
| 门店配合卡住 | 对方职责、资源、日期、依赖和利益是否清楚 | 可直接沟通的内容或分工调整草稿 |
| 效果不好 | 事前预期、执行是否完成、客人反应、同口径结果、同期变化 | 继续／调整／停止／观察及依据；不把相关当因果 |

对话宜一次解决一个关键选择。能给出有根据的建议就先给，再问真正会改变建议的问题。可以一次问一至三个相关问题，但不把数量限制当截断完整工作的理由。

用户只需短答案时，不创建月度方案、推进表或日报。用户要实际结果时，在当前授权内完成：如一条话术、一组内容、一个活动草案或已有项目修订。

若当前事实发生实质变化，按门店资料规则更新本地当前记录，并说明改了哪项判断。方法候选保留适用条件与反例；未经依据不改全体门店规则。

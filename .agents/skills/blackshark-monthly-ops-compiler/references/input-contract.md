# 输入约定 v0.3

可以从一句问题、一份整体方向、会议记录、半成品方案或已有表开始。先读用户已给内容，再问本轮真正缺的条件。

- 月度规划需要识别门店和月份；未明确且上下文不能确定时询问。
- 已定的主攻、次线、不做和资源范围继承。未定方向允许先建议，不冒充拍板。
- 负责人、期限、预算从材料提取；缺失时继续工作稿，并标明影响哪项任务。
- 正式执行中，未定预算／资源承诺及任务责任由相应有权者决定。旧审批已有效时直接承接。

读取根目录 `01_shared_context/门店资料使用与更新.md`。原会议并非唯一合法输入，完整月度材料也不是日常求助的前置。

有地图沿实际路径；无地图但工作台完整时，对话继续，用户要求生成文件则用 manifest 默认个人目录并说明位置。需要迁移、外部目录或存在同名冲突时才处理相关位置决定。

建议本期目录：`projects/YYYY-MM-门店/00_input` 保存原文，`01_context` 关联当前事实，`02_drafts` 保存工作稿和机器记录，`03_verification` 保存检查与外部ID。这些由 AI 按需要建，不要求用户手动配置。

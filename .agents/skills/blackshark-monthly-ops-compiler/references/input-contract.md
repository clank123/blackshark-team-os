# 输入合同

## 必填输入

- 目标门店：必须能对应七店索引中的一张门店卡。
- 目标月份：使用 `YYYY-MM`。
- 原始月度会议材料：会议文档、纪要、逐字稿或本地文本至少一种。
- 主方向：每月一个，必须来自已确认会议结论。
- 次方向状态：0—2 个，若没有必须明确写“无”。
- 最后拍板人：负责方向、资源与争议的最终决定。
- 运营推进人：负责拆解、追踪与回收。
- 门店落地人：负责现场执行与证据反馈。

缺少任一必填输入时，输出缺口清单，不生成正式方案。

## 选填输入

- 上月未结束事项。
- 最新经营与平台数据，包含指标口径和数据周期。
- 品牌节点、产品节点和场地节点。
- 人力、预算、供应与时间限制。
- 本月明确不做的事项。
- 待拍板事项及最晚决定日期。
- 用户对旧门店卡的明确纠正。

选填输入缺失不必阻止编译；若它会影响方向可信度，则在预览中标记风险或“待门店确认”。

## 本月项目目录

```text
03_projects/YYYY-MM-门店名称/
├── 00-input/       原始会议材料和用户补充
├── 01-draft/       发布前预览与草稿
├── 02-output/      最终文档正文、推进表记录和入口
└── 03-verification/回读结果与验收记录
```

如目录尚不存在，可在本机创建；不得把本月原始材料写入共享上下文或门店卡目录。

## 真值优先级

`本月已确认会议事实 > 门店卡当前状态 > 门店卡长期基因 > 通用经营框架`

- 本月会议中的“讨论”“建议”“可能”不属于已确认事实。
- 新事实可以覆盖旧的当前状态，但要保留来源和日期。
- 长期基因发生明确变更时，把证据列入 `05_reviews/月度复盘候选/`，不得静默覆盖门店卡。
- 不同来源无法按优先级消解时，保留冲突并进入待拍板。

## 材料解析规则

把材料逐项标记为：

1. 已确认会议事实。
2. 已确认方向。
3. 待拍板。
4. 本月不做。
5. 现场观察或假设。

只有前两类可以直接进入正式方案的确定性表达；其余内容必须保留原有不确定性。

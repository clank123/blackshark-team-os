# 4. 各板块怎么落地

## 门店日常

- 要解决的问题：套餐、平台信息与现场说法可能不一致。
- 核心做法：逐项核对并整理评价处理与接待清单。
- 验收证据：核对结果和可使用清单。
- 对应推进表动作：核对套餐与平台信息；整理评价处理与接待清单。

## 私域轻动作

- 要解决的问题：轻量私域动作规则尚未拍板。
- 核心做法：先提交规则说明，拍板后再执行。
- 验收证据：拍板记录与最终规则。
- 对应推进表动作：确认私域轻动作规则。

# 5. 本月先不做什么

- 不做大型布置：本月优先稳定基础经营动作。
- 不新增额外系统：保持交付边界简单。

1. 经营方向、取舍与做法只在本文档维护。

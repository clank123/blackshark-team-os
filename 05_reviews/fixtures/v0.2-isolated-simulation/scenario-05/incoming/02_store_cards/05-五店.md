# 基础身份

- 门店：五店／胡子精酿全球酿造中心
- 位置：福州台江区 318 创意园区
- 类型：前店后厂、品牌窗口与综合体验店

# 品牌关系与门店角色

- 主角色：胡子品牌第一入口和口碑窗口。
- 次角色：318 园区活动主场与综合消费承接。
- 成功信号：第一次来胡子的人获得“果然值得来”的正确第一印象。

# 核心客群

- 有消费力、愿意为体验买单的白领和朋友局用户。
- 第一次认识胡子的用户、园区流量客和活动参与者。
- 不以纯低价消费或强商务应酬为核心。

# 核心场景和体验

- 关键词：入门、窗口、综合体验、活动主场。
- 体验：第一次来就能理解胡子为什么成立，并愿意把它推荐为品牌首选入口。

# 主时段与弱时段

- 历史主时段与利润时段：21:00—24:00。
- 活动日、周末和园区高活跃时段更强。
- 非晚间和园区低流量时段相对较弱，当前结构待确认。

# 产品结构和优势资产

- 酒水、胡烤、孤独汉堡组成综合体验。
- 优势资产：前店后厂、酒罐设备、餐酒联动、活动密度、口碑与评分。

# 适合动作

- 品牌节点、活动主场、综合体验设计、首试引导。
- 园区联动、窗口型传播、新品入门教育。

# 禁止动作

- 牺牲现场体验和口碑换流量。
- 多个活动无序堆叠，超过现场承载。
- 只看热闹、曝光和报名，不看真实消费与复来线索。

# 长期基因

五店是胡子最成熟的品牌窗口之一。它可以承接重节点，但每次放大都必须保护第一次到店体验、服务秩序和“第一次来胡子先来这里”的推荐心智。

# 输入合同

## 地图与目录 Gate

起手读取 `00_workspace/工作台地图.local.md`，并从地图定位个人项目目录和正式产物目录。地图缺失，或地图中的路径失效时，停止当前编译并返回 `$blackshark-ops-router` 重新匹配；不得猜测路径或在猜测位置创建文件。

默认的本月项目目录为：

```text
03_my_workspace/01_projects/YYYY-MM-门店名称/
├── 00_input/        原始会议材料和用户补充
├── 01_context/      本月使用的上下文索引和来源说明
├── 02_drafts/       编译草稿和本地预览
└── 03_verification/ 本地及可选飞书验收记录
```

默认正式输出目录为 `03_my_workspace/02_outputs/YYYY-MM-门店名称/`。如操作者已在地图中配置其他有效路径，使用地图中的实际路径。不得把本月原始材料写入共享上下文或门店卡目录。

## 必填输入

- 目标门店：必须能对应七店索引中的一张门店卡。
- 目标月份：使用 `YYYY-MM`。
- 原始月度会议材料：会议文档、纪要、逐字稿或本地文本至少一种。
- 主方向：每月一个，必须来自已确认会议结论。
- 次方向状态：0—2 个，若没有必须明确写“无”。
- 最后拍板人：负责方向、资源与争议的最终决定。
- 运营推进人：负责拆解、追踪与回收。
- 门店落地人：负责现场执行与证据反馈。

缺少任一必填输入时，输出缺口清单，不生成正式方案。

## 选填输入

- 上月未结束事项。
- 最新经营与平台数据，包含指标口径和数据周期。
- 品牌节点、产品节点和场地节点。
- 人力、预算、供应与时间限制。
- 本月明确不做的事项。
- 待拍板事项及最晚决定日期。
- 用户对旧门店卡的明确纠正。

选填输入缺失不必阻止编译；若它会影响方向可信度，则在预览中标记风险或“待门店确认”。

## 真值优先级

`本月已确认会议事实 > 门店卡当前状态 > 门店卡长期基因 > 通用经营框架`

- 本月会议中的“讨论”“建议”“可能”不属于已确认事实。
- 新事实可以覆盖旧的当前状态，但要保留来源和日期。
- 长期基因发生明确变更时，把证据存入 `05_upstream_candidates/`，不得静默覆盖门店卡。
- 不同来源无法按优先级消解时，保留冲突并进入待拍板。

## 材料五分类

把材料逐项标记为：

1. 已确认会议事实。
2. 已确认方向。
3. 待拍板。
4. 本月不做。
5. 现场观察或假设。

只有前两类可以直接进入正式方案的确定性表达；其余内容必须保留原有不确定性。

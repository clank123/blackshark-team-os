## 哈希合同

- 编码固定为 UTF-8；每条记录严格为 `relative_path<TAB>byte_size<TAB>file_sha256<LF>`。
- `relative_path` 以各清单范围根为基准，使用 POSIX `/`，不得是绝对路径，不得包含 `..`。
- 记录按 `relative_path` 的 Unicode code point（Python str 顺序）升序排列，每条包含末尾 LF。
- aggregate 为串联后 UTF-8 bytes 的 SHA-256；空清单为 SHA-256(empty bytes)。
- JSON 保存 before/after、Scenario 1/2 的两次确认前完整范围快照和 staging 逐文件条目，可直接复算；公开记录不保存隔离根绝对路径。
- `artifact_inventory` 全部以 `package-root` 为范围，直接绑定本包公开 fixture 或当前关键源载荷本体；`artifact_sha256` 是它的精确投影。
- 输入样板使用包内公开 fixture 的实际 UTF-8 bytes 计算，不依赖包外 fixture。

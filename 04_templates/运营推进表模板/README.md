# 运营推进表模板 0.2

每店每月一张业务表。保留原10个业务字段，新增任务编号和父任务两个关系字段；六状态、五个默认视图继续保留。schema.json 是本包的语义定义，不是飞书 API payload。

主项目 → 可展开的子任务。父任务字段建立数据关系，原生展开需要另外配置；飞书方案里再插入真实表视图。三件事分别验证，CSV 导入本身不算完成。

任务编号由 AI 维护，标题修改不改变编号。人员、日期和预算未知时先做工作稿；正式任务下发前补相应缺口。主项目完成需子项和项目自身验收成立，不以发布文件为完成。

旧表升级时映射已有字段、状态、视图与记录，保留执行中的实际内容。技术列可在门店视图隐藏；不要要求运营手填 ID。可见字段和模板变化记录版本，不能自动改全体旧表。

参见 Skill 的输出与发布约定，以及根目录 scripts/compile_monthly.py。

# 运营推进表模板

这张表只负责推进，不承担月度方案正文。一个月份只建一张“本月推进表”，所有动作都在同一张业务表里管理。

## 十个字段怎么用

| 字段 | 用法 |
| --- | --- |
| 动作 | 一行写一个可交付、可验收的动作 |
| 执行线 | 标记动作属于哪条经营执行线，可按当月方案设置选项 |
| 状态 | 只使用六个固定状态，方便统一筛选 |
| 归属 | 标记由黑鲨还是目标门店承担 |
| 交付物/验收 | 写清完成的证据，而不是只写“做完” |
| 实际情况记录 | 执行后记录真实结果、偏差和现场反馈 |
| 截止日期 | 最晚交付日期 |
| 开始日期 | 预计或实际启动日期 |
| 承接人 | 对这一行结果负责的唯一主承接人 |
| 阻塞/待确认 | 写卡点、需要谁决定，以及最晚确认时间 |

## 五个固定视图

- 全部推进：查看所有动作，并按截止日期排序。
- 本月排期：用开始日期和截止日期查看整月节奏。
- 按承接人：检查每个人承担的动作和截止日期。
- 待拍板与阻塞：集中处理无法继续推进的事项。
- 门店要做：只给门店看尚未结束、由门店承接的动作。

## 默认任务量

常规月份通常会形成 20—30 条动作，但任务数必须由真实经营板块决定。不要为了凑数拆出没有独立交付物、没有独立承接人或没有经营意义的动作。

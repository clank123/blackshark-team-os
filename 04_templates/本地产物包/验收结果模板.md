# 验收结果

- 本地结构验收：未检查
- 发布请求状态：未请求
- 飞书发布状态：未请求
- 飞书回读状态：未开始
- 未通过项：
- 验收时间：

## 状态填写合同

本地结构验收只填写“未检查”“通过”或“未通过”中的一个值。每个发布状态字段也只填写一个合法值，并只允许以下组合：

1. 本地完成、未请求发布：`未请求 / 未请求 / 未开始`。
2. 已请求但没有权限：`已请求 / 已尝试 / 未开始`，并在未通过项写明“权限不足”。
3. 部分写入：`已请求 / 已尝试 / 未验证`。
4. 已写入但回读失败：`已请求 / 已发布 / 未验证`。
5. 发布及回读完整通过：`已请求 / 已发布 / 通过`。

出现候选多值或任何非法组合时，验收失败，并写入未通过项。

只有本地结构验收通过，才报告“本地交付完成”；本地完成不等于已发布飞书。

只有飞书发布成功且回读通过，才报告“已发布并验证”。发布成功但回读未通过时，只能报告“已尝试发布，尚未验证”。

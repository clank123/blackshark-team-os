## 状态填写合同

每个状态字段只填写一个合法值：发布请求状态为“未请求”或“已请求”；飞书发布状态为“未请求”“已尝试”或“已发布”；飞书回读状态为“未开始”“未验证”或“通过”。只允许以下组合：

1. 本地完成、未请求发布：`未请求 / 未请求 / 未开始`。
2. 已请求但没有权限：`已请求 / 已尝试 / 未开始`，并在未通过项写明“权限不足”。
3. 部分写入：`已请求 / 已尝试 / 未验证`。
4. 已写入但回读失败：`已请求 / 已发布 / 未验证`。
5. 发布及回读完整通过：`已请求 / 已发布 / 通过`。

出现候选多值或任何非法组合时，验收失败；不得声称发布成功或回读通过。

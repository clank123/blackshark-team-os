# 本地产物包

本目录定义月度编译器的五件正式本地产物。生成时使用下表中的固定文件名、来源模板、职责和顺序。

| 生成顺序 | 固定文件名 | 来源模板 | 职责 |
| --- | --- | --- | --- |
| 1 | `本月运营方案.md` | `../月度运营方案模板.md` | 保存文档头和七段式 Markdown 正文。 |
| 2 | `运营推进表.csv` | `运营推进表.csv` | 保存严格按十字段排列的动作记录。 |
| 3 | `运营推进表结构.json` | `../运营推进表模板/schema.json` | 保存一张业务表、十字段、六状态和五视图的 schema。 |
| 4 | `发布说明.md` | `发布说明模板.md` | 记录可选发布目标、请求、状态和手动导入说明。 |
| 5 | `验收结果.md` | `验收结果模板.md` | 分开记录本地结构验收、飞书发布和飞书回读状态。 |

五件文件都不得含凭证、令牌、密钥或超出任务范围的私密材料。发布说明只记录位置描述和状态，不保存鉴权信息。

生成本地 `本月运营方案.md` 时，将“配套推进表入口”写为 `[运营推进表.csv](./运营推进表.csv)`，并可同时链接 `[运营推进表结构.json](./运营推进表结构.json)`。飞书发布时只在外部副本中替换为实际 Base 地址，不修改本地方案。

正式五件产物必须全部完成变量解析。本地验收逐件扫描 `{{` 和 `}}`，任一文件仍有占位符即失败，不得报告本地完成；`运营推进表结构.json` 的目标门店、动态执行线等必须写入本月实际值。
